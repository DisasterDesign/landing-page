## 2. הטכנולוגיה (לב הסרטון)

### שלושה קווי עסק
1. **Geothermal power** — הליבה. חום ממאגרים תת-קרקעיים → חשמל.
2. **Recovered Energy Generation (REG)** — לכידת **חום-פסולת** תעשייתי (פליטת מדחסים בצנרת גז ב-850–950°F) והמרתו לחשמל ללא דלק נוסף. אותו מנוע ORC, מקור חום אחר.
3. **Energy Storage** — פרויקטי **סוללות רשת (BESS)**. חדש וצומח, אך פחות ויזואלי לסרט 3D מהחומרה הגיאותרמית.

### Ormat Energy Converter (OEC) — האובייקט-גיבור
יחידת הספק ארוזה מבוססת **Organic Rankine Cycle (ORC)**. הרעיון לדרמטיזציה: מחזור ראנקין רגיל (מים) דורש קיטור בטמפ' גבוהה; **הנוזל האורגני** (פנטאן/איזובוטאן/בוטאן — נק' רתיחה נמוכה בהרבה מהמים) מאפשר להפיק הספק מחום בטמפ' נמוכה/בינונית שאחרת היה מבוזבז. זה ה"רגע הקסום" של הסרט: *נוזל שרותח איפה שמים לא יכולים.*

### החומרה (מה שנראה מרשים ב-3D)
| רכיב | תפקיד (שורה) |
|---|---|
| באר הפקה + משאבת מעמקים | מעלה תמלחת גיאותרמית חמה מהמאגר לפני השטח. |
| ראש באר + צנרת מבודדת | מנתב את התמלחת החמה מהשדה לתחנה בלחץ. |
| מחמם מקדים (Preheater) | התמלחת מחממת ראשונית את הנוזל האורגני הקר לקראת רתיחה. |
| מאדה (Vaporizer/Evaporator) | תמלחת חמה יותר **מרתיחה** את הנוזל לאדים בלחץ גבוה — הטרנספורמציה המרכזית. |
| טורבינה (Turboexpander) | אדים בלחץ גבוה מתפשטים ומסובבים את הטורבינה — חום → סיבוב. **שוט היופי החתימתי.** |
| גנרטור | צמוד לציר הטורבינה; סיבוב → חשמל (פריים השיא). |
| Recuperator (אופ') | משחזר חום שיורי מאדי-הפליטה לחימום מקדים — פרט יעילות. |
| מעבה אווירי (Condenser) | מקרר אדים מנוצלים חזרה לנוזל. אווירי = חתימת Ormat (לא צורך מים). |
| משאבת הזנה | מלחיצה את הנוזל המעובה ודוחפת חזרה למחמם — סוגרת לולאה. |
| באר הזרקה | מחזירה את התמלחת הקרה לאדמה — **~100% reinjection** משמר את המאגר. |

### זרימת האנרגיה (storyboard-ready)
תמלחת חמה עולה בבאר ההפקה → מחמם מקדים → מאדה (הנוזל האורגני רותח) → אדים בלחץ גבוה מסובבים את הטורבינה → הטורבינה מניעה את הגנרטור → חשמל לרשת → אדים מנוצלים מתקררים במעבה האווירי חזרה לנוזל → משאבת ההזנה מלחיצה מחדש → חזרה למחמם (לולאה סגורה). במקביל התמלחת **מוזרקת חזרה** לאדמה דרך באר ההזרקה. **שתי לולאות סגורות שלובות** (נוזל-עבודה + נוזל-גיאותרמי) — המבנה הנקי ביותר לאנימציה.

**קולאאוטים מבדלים:** binary/closed-loop (אפס פליטות); ~100% reinjection + קירור אווירי (אפס צריכת מים); baseload 24/7; אותו מנוע לשלושה מקורות חום (גיאותרמי / חום-פסולת / סולארי-תרמי היסטורי).

*(מקורות: עמודי Ormat binary/ORC/REG; ScienceDirect "Binary Geothermal Power Plant"; פטנט US8601814B2.)*

- **צבעי מותג (הראיה הטובה ביותר):** **נייבי ~#012D5C** (דומיננטי), **לבן #FFFFFF**, אקצנט **זהב "husk" ~#BC9C4F**. *(Brandfetch.)* מקור אחר דיווח אדום #E20612 — כמעט בוודאות artifact אוטומטי שגוי; **להתעלם מהאדום.**
- **לוגו:** Wordmark "ORMAT" (לעיתים + "TECHNOLOGIES"), sans גאומטרי נקי, תאגידי ומאופק.
- **טיפוגרפיה:** sans הומניסטי/גאומטרי, הנדסי-אמין, לא שובב. *(הגופן המדויק לא אומת.)*
- **דימויים:** תעשייה-פוגשת-טבע — תחנות אמיתיות מול נופים דרמטיים (מדבר, אדי גייזר, שטח וולקני), צנרת פלדה ומאווררי מעבה, צילומי רחפן. נקי, שעת-זהב, תשתית-כגיבור.
- **טון:** תאגידי + הנדסי + מעוגן-קיימות. דגש: *"We're always on."* אמינות ו-24/7 baseload הם עמוד השדרה הרגשי — לא אשמה אקולוגית. בוטח, בוגר, incumbent.

## 4. כיוון יצירתי לסרטון

### מה הסרט צריך להדגיש
Ormat אינה סטארטאפ — היא ה-**incumbent בן 60 שנה שהמציא את הקטגוריה ועדיין בונה את החומרה**. הסרט צריך למכור **אמינות הנדסית + אלגנטיות המכונה הסגורה + "always on"** אל מול מתחדש לסירוגין. להוביל עם **החומרה והפיזיקה** (ה-OEC, הנוזל הרותח, הטורבינה המסתובבת, שתי הלולאות), לא stock גנרי של "אנרגיה ירוקה". המבדל לדרמטיזציה: **חום שכולם זורקים → חשמל נקי 24/7, והנוזל של כדור הארץ חוזר ישר פנימה.**

### מבנה 3 דקות מוצע (~180 ש')
1. **HOOK (0:00–0:20)** — פנים כדור הארץ זוהר בחום; "מתחת לרגליים שלך מקור כוח שלא ישן." סקייל + always-on.
2. **PROBLEM (0:20–0:45)** — סולארי נעצר בלילה, רוח כשאין רוח; חום נמוך-דרגה עצום (מאגרים, פליטה תעשייתית) מבוזבז כי טורבינות קיטור לא יכולות ללכוד אותו.
3. **TECHNOLOGY — OEC (0:45–1:50, מרכז ~65ש')** — טיסה לתוך ה-OEC. הנוזל האורגני **רותח** בטמפ' נמוכה (הרגע הקסום). מעקב אחר הלולאה רכיב-רכיב עם תוויות: באר → מחמם → מאדה → טורבינה (שוט-גיבור) → גנרטור → מעבה אווירי → משאבה → חזרה; תמלחת מוזרקת. דגש: לולאה סגורה, אפס פליטות, אפס מים.
4. **BREADTH/IMPACT (1:50–2:35)** — אותו מנוע, שלושה מקורות: שדות גיאותרמיים, **REG** בתעשייה, אחסון רשת. zoom-out למפת עולם / 190+ תחנות / 24-7 baseload לבתים, בתי חולים, datacenters.
5. **OUTRO/BRAND (2:35–3:00)** — נייבי נקי, לוגו, "Always on", "Pioneering renewable power since 1965".
