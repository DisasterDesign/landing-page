# SPEC — דף הצגה/הצעה ל-Ormat (ormat.fuzionwebz.com)

**תאריך:** 2026-06-28 · **סטטוס:** ממתין לאישור אלעד לפני בנייה.

---

## 1. מטרה
דף נחיתה פרימיום בסאב-דומיין `ormat.fuzionwebz.com` שמתפקד כהצעת מחיר + חוזה: מציג את קונספט הסרטון ל-Ormat, סוקר את התנאים, אוסף **חתימה דיגיטלית**, ומעביר ישירות ל**תשלום ראשון** (Cardcom). הדף עצמו הוא החוזה. המחיר: **₪75,000 + מע"מ (₪88,500)**, 4 תשלומים.

## 2. ארכיטקטורה — להישען על הקיים, לא לבנות מחדש
האפליקציה `fuzion-webz` היא **Next.js (App Router) על Vercel**, וכבר מכילה את כל אבני הבניין:
- מודל `Agreement` + חתימה ב-`signToken` + קנבס חתימה (`src/app/agreement/[token]/SignAgreementClient.tsx`).
- Cardcom LowProfile + webhook + דפי `payment/success|failed` (`src/lib/cardcom.ts`, `src/lib/payments.ts`).
- טוקנים עיצוביים (Birzia/Meruba, ורוד `#E503A2` / ציאן `#01FFFF`, רקע שחור, גריד, shader 3D ב-`HeroGlass`).
- ספריות אנימציה כבר מותקנות: `three ^0.183`, `@react-three/fiber ^9.5`, `@react-three/drei ^10.7`, `framer-motion`, `gsap`, `lenis`.

**החלטות ארכיטקטורה:**
1. **קוד הדף** = route group חדש בריפו: `src/app/(proposal)/ormat/` (+ קומפוננטות ב-`src/components/proposal/` ו-`src/components/three/ormat/`).
2. **ניתוב סאב-דומיין** דרך `src/middleware.ts` (rewrite של host `ormat.fuzionwebz.com` → `/ormat`), כך שה-URL ללקוח נקי. דומיין נוסף ב-Vercel + CNAME.
3. **חתימה+תשלום** — מחברים ל-flow הקיים. דחינו: ריפו נפרד / דף סטטי / מנגנון חתימה חדש (= בנייה מחדש מיותרת).
4. **מודל תשלום** — "עד 4 תשלומים שאפשר לעצור" = **חיוב לפי אבני דרך**, לא תשלומי כרטיס אשראי. הדף גובה **רק תשלום 1** (₪26,550) דרך Cardcom; 2–4 הם חיובים נפרדים בכל milestone (ידני). תוספת סכמה מינימלית: שדה/JSON לרישום מסלול אבני הדרך על ה-`Agreement` (או מודל `Proposal` קל אם עדיף — להכריע בתוכנית). **db push לפני git push** (חובה, ראה memory).

## 3. הקונספט היצירתי — "טיפת האנרגיה במעגל הסגור"
גלילה אנכית (RTL, עברית, מותג Fuzion כהה). קנבס 3D מקובע (pinned) ברקע; הגלילה דוחפת **טיפת נוזל אורגני** זוהרת דרך המעגל הסגור האמיתי של Ormat. כל **תחנה במכונה = סקשן בחוזה**. 3D **פרוצדורלי/מסוגנן** בסגנון ה-shader הקיים (לא מודלים סרוקים מהאינטרנט — סיכון רישוי/איכות).

## 4. רכיבים (units)
- `OrmatScene` (three/R3F): מכונה פרוצדורלית + טיפה + תוויות; נשלט ע"י scroll progress. גרסת **fallback** סטטית למובייל / `prefers-reduced-motion`.
- `ScrollController`: ממפה scroll → progress (Lenis קיים). חושף ערך 0–1 ל-Scene ולהדגשת סקשנים.
- `ProposalSection`: עטיפת סקשן (כותרת + תוכן + עוגן לתחנה).
- `VideoCarousel`: קרוסלת דוגמאות; קורא נכסים מ-`public/ormat/showcase/` עם config; ריק בחן (placeholder) עד שאלעד יצרף.
- `OrmatSignBlock`: עטיפה סביב לוגיקת החתימה הקיימת + שדות → POST קיים → `paymentUrl`.
- `priceTable` / `milestones`: נתון יחיד מקור-אמת (גם בחוזה, גם בתצוגה).

## 5. עיצוב
מותג Fuzion כהה: רקע שחור, ורוד/ציאן, Birzia (גוף) / Meruba (כותרות), גריד, chromatic aberration לכותרות-על. נגיעת נייבי/זהב של Ormat **רק** בזוהר ה-3D (הטיפה/האנרגיה), לא ב-UI. נגישות: reduced-motion, ניגודיות, פוקוס מקלדת — לפי הקיים.

## 7. תוכנית דיפלוי
1. בנייה + `npm run build` ירוק מקומית.
2. push לענף → Vercel preview.
3. הוספת דומיין `ormat.fuzionwebz.com` ב-Vercel + רשומת CNAME ב-DNS. **שלב זה עשוי לדרוש את אלעד** (גישת דשבורד Vercel/DNS) — יסומן במפורש כשנגיע.
4. אם יש שינוי סכמה: **`prisma db push` לפרודקשן לפני git push** (auth/agreement קוראים את הסכמה).
5. smoke test על הסאב-דומיין: טעינה, גלילה+3D, חתימה, יצירת `paymentUrl` של Cardcom (test mode לפני live).
