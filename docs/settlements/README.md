# רישום התחשבנויות אלעד ↔ רועי

קובץ אחד לחודש, `YYYY-MM.md`. זה **הרישום היחיד** של מה הועבר לרועי — אין טבלה
כזו ב-DB. לפני שמעבירים לחודש, בודקים שאין כאן קובץ לאותו חודש בסטטוס "שולם".

הנוהל המלא: `docs/PARTNER-SETTLEMENT.md`.
